# Code of Conduct

## Our standard

Everyone participating in this project — reviews, issues, commits — is
expected to be technically rigorous and personally decent. Disagree with
evidence, cite file:line, and keep findings contestable; do not attack
people.

## Contestable findings

A review finding may be contested only with evidence the reviewer could
read: a file and symbol, a spec clause, or command output. "This was
intentional" is not evidence. Do not change a finding's severity while
contesting it.

## Scope

Applies to all project spaces: commits, code review, issues, and the docs
tree under `docs/`. Violations escalate to the owner (Quy Doan).
