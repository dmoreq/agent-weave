## Miss analysis (4 missed symbols, 3 queries)

1. `src.journal.rotate_if_needed` ("journal payload rotation size threshold"):
   the qualname splits to `journal rotate if needed` — the query tokens
   "rotation" (vs "rotate": prefix direction is query-token-first, so
   "rotation"* does not match "rotate") and "size"/"threshold" (present only
   in constants, not the symbol) pull the ranking to journal-neighbors.
2. `src.db.load_carried` + `src.doctor.stale_ratio`: second expects whose
   sibling (the primary symbol) hit; bm25 ranked 10+ same-token rows above
   them at --limit 10.
3. `...HierarchicalAddressParser.parse` ("parse address pipeline entry"):
   documented query-contract mismatch above.

All four are ranking/limit effects, not index gaps — each target IS indexed
and reachable with its own tokens (verified: `kg search rotate if needed`
finds `rotate_if_needed`).
