## Important findings

1. All 58 valid cells are correct; verdicts are tool-economy-only.
2. The sanitized corpora have no `.git`; `kg` without `--root` fails and is
   retried. At least 25/30 treatment cells pay one extra call. This is a
   harness defect, not a feature cost.
3. Every measured task is grep-solvable on the tiny corpora. The battery
   measures whether the agent knows the right grep plus CLI fixed cost, not a
   capability grep lacks.
4. D1 is the only robust positive: treatment below control in all six paired
   runs and all three valid hosts.
5. A1 is a robust negative: 15 interfaces are one grep; treatment adds calls.
6. T1 is artifact-sensitive and direct-only.
7. H1 has an agy control that used `dead`/`context`, outside the frozen control
   set; prompt and protocol disagree on the forbidden list.
8. `kg imports` returns 5 rows (modules + symbols), not the 3 oracle modules;
   agents must filter.
9. Agy journal telemetry is empty; latency comes from transcript parsing.
10. Features with no utility task are "not measured", not "no value shown".
