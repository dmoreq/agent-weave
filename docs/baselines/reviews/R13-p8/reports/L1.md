## Important findings

1. F1 GT construction protocol claims imported/cross-file bases, but frozen
   rows are same-file only. A source AST derivation finds 15 internal vihap rows;
   `implementers AddressCleaner` and `BaseSpanMatch` return the omitted
   cross-file children.
2. F1 cross-file TS alias extension is missed:
   `apps/prototype/src/app/providers/demo-ledger-context.ts` imports
   `TransactionProposal` from `@finguard/core-ledger` and extends it; kg exits 1
   and stores an unresolved inherit row.
3. F7 GT provenance/count drift: GT doc says vihap 25/kg 15; JSONL has 26/14.
   The frozen set is a 40-row sample of 1,768 emitted vihap rows, with no
   documented sampling rule.
4. F8 precision is duplicate-inflated and name-shape-only: 2,679 emitted rows
   but 782 unique `file:line`; no must-not-report controls.
5. F10 cannot answer Rust crate-root public surface: `kg api src/lib.rs` exits 1
   with 0 exported symbols although `src/lib.rs` has 14 `pub mod`.
6. Review provenance drift: HEAD moved from `0b51585`; repo binary was stale.
   Final probes used the frozen archive.

## Suggestions

- F3: whitespace-padded `--path` passes validation but returns 0.
- F2: `[ambiguous]` tag is unreachable; AMBIGUOUS sites are omitted.
- F5: default `unresolved` does not filter/count `site_line=0` like `--names`.
- F10: raw/prefixed Python `__all__` literals not parsed.
- F9: elif nesting differs from Python AST depth; semantics unpinned.
- F11: add committed `gen/` and bare `DO NOT EDIT` negative tests.
- F4: document or reject `--context --depth >1`.
- F6: document MCP resolve error-carrier contract.
