# F2 — Impact caller context

Question: which function or method contains an impacting call/import/inherit site?

Surface: `kg impact <FILE> --context` at depth 1; with `--sites` and `--explain`; no `callers/callees --context`.

Code: `src/query.rs` `impact`, `impact_detail`, per-site mode.

Tests: `tests/cli.rs` `impact_context_tags_only_callable_sites`; `impact_defaults_to_files_with_site_counts`; related impact tests.

Limits: only callable source sites get `[in qualname]`; module/class/lambda sites keep `path:line`; ambiguity tag is currently unreachable because impact joins resolved `dst_id` and AMBIGUOUS edges have NULL destination.

Raw utility coverage: no dedicated P8 utility task. Older `kg context` A/B exists but is a different command.

Consumers: `kg-first`, `code-index`, README, MCP `impact`.

Coupling: shares impact BFS/grouping with F4; context annotation depends on source symbol kind.
