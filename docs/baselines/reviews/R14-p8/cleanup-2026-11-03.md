# R14 cleanup — ineffective surfaces (2026-11-03)

Owner instruction: clean up ineffective features. Implements D1-D3 from the
R14 owner packet as code removal; D4 (`dead` routing) stays a routing-only
demote.

## Removed

| Surface | Removed from | Kept |
|---|---|---|
| `kg api` (F10) | CLI enum/dispatch, MCP tool and schema, `query::api`, payload/journal row, 6 tests, README/skill lines | `symbols.exported` column and extraction for schema compatibility |
| `search --kind/--path/--exact` (F6) | CLI/MCP fields, query filters, exact-branch, journal args, tests, README claim | Base `kg search <terms>`, qualified-identity fast path |
| `--exclude-generated` (F11) | CLI/MCP fields on `dead`, `clones`, `hotspots`, `report`, `complexity`; query/insights filters; tests | `files.generated`, `is_generated`, `stats generated=N`, generated tag |
| `dead` routing (F1) | `kg-first` routing row | `kg dead` command, tests, caveat |

No schema column was dropped. Schema stays v7. Package version moves to
`0.3.0` because the CLI/MCP contract is breaking.
