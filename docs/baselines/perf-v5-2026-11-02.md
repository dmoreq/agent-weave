## Operating envelope (measured)

- Tested safe: ≤ 2,025 files / 85k symbols / 164k edges (committed synth);
  11,275 files / 139k symbols / 722k edges (vscode `src/`, R6g) with queries
  < 10 ms and build 24.6 s / 1.04 GB RSS.
- Memory scales with corpus size (build materializes extraction; no-op rebuild
  repopulates FTS). Query memory is now bounded by the display cap.
- Known-bad input shapes are bounded, not fatal: deep nesting is skipped past
  MAX_AST_DEPTH; clone regions/pairs are capped with a lower-bound note;
  search terms cap at 32; MCP frames cap at 8 MiB.
- Unresolved share is corpus-dependent (measured 51.8-90.4% across six
  corpora; Django 71.7%, vscode 62.9%) and is reported per file by
  `kg unresolved`.
